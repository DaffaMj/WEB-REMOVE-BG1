**The Remove Background Web App** is a Python-based project built using Flask, designed to automate the process of removing image backgrounds with high accuracy. This project utilizes the Rembg library and Pillow (PIL) to process images locally, allowing users to upload photos and instantly receive background-removed output.
The application includes a clean and modern HTML/CSS interface for easy interaction, featuring drag-and-drop upload, instant preview, and downloadable output images. All image processing is done on the backend using Python.

**Tools: **
Visual Studio Code, Python, Flask, Rembg, Pillow (PIL), HTML, CSS, JavaScript

**Programming Language:**
Python, HTML, CSS, JavaScript (Front-end interface)

**Backend: **
Python Flask, Rembg (background removal engine), Local file storage for input/output images
